========================================================================
                  คู่มือการใช้งานโปรแกรม "Prince Studio"
               (Facebook Page Studio — SocialManager.exe)
========================================================================

โปรแกรม "Prince Studio" คือแอปเดสก์ท็อปสำหรับจัดการและโพสต์ลงเพจ Facebook
หลายเพจพร้อมกันผ่าน Facebook Graph API อย่างเป็นทางการ พร้อมระบบตั้งเวลา,
คิวทำซ้ำ, ประทับลายน้ำ, Spintax, จัดการคอมเมนต์ และผู้ช่วยแชร์โพสต์
ออกแบบด้วยฟอนต์ไทยไม่มีหัว (Prompt) และรองรับทั้งโหมดมืด/โหมดสว่าง

ตำแหน่งเก็บข้อมูลของโปรแกรมในเครื่อง:
  - ฐานข้อมูลและการตั้งค่า: C:\Users\<ชื่อผู้ใช้>\.social_manager\
    (ไฟล์ data.db และ settings.json)
  - Token และ App Secret: เก็บเข้ารหัสอย่างปลอดภัยใน Windows Keychain

------------------------------------------------------------------------
สารบัญ
------------------------------------------------------------------------
  1. การเริ่มต้นใช้งานและตั้งค่าการเชื่อมต่อ Facebook (3 รูปแบบ)
  2. ภาพรวมหน้าจอ: แถบด้านซ้าย (Sidebar) และแถบสถิติ KPI ด้านบน
  3. หน้า 1: เขียนโพสต์ (Composer) & พรีวิวแบบเรียลไทม์
  4. ระบบ Spintax, ตัวแปรไดนามิก, ลายน้ำอัตโนมัติ และบันทึกฉบับร่าง
  5. หน้า 2: คิวตั้งเวลาในเครื่อง (Local Queue) & การนำเข้า CSV
  6. หน้า 3: ประวัติการโพสต์ (History), ดูสถิติ, แก้ไข และลบโพสต์บน FB
  7. หน้า 4: คอมเมนต์ใต้โพสต์, กล่องตอบ/ซ่อน/ลบคอมเมนต์ & เพจอื่น
  8. หน้า 5: แชร์โพสต์ลงเพจตัวเอง และสมุดบันทึกกลุ่ม (Quick Share)
  9. การทำงานเบื้องหลังผ่าน System Tray และการสำรองข้อมูล (Backup DB)
 10. คำถามที่พบบ่อยและการแก้ปัญหาเบื้องต้น

========================================================================
1. การเริ่มต้นใช้งานและตั้งค่าการเชื่อมต่อ Facebook (3 รูปแบบ)
========================================================================

กดปุ่ม "ตั้งค่า" ที่มุมล่างซ้ายของแอป หน้าต่าง "ตั้งค่าการเชื่อมต่อ Facebook"
มี 3 แท็บให้เลือกตามลักษณะการใช้งาน:

[รูปแบบที่ 1] แท็บ "1. ตั้งค่าเอง (Wizard)" — ใช้ Meta App ของตัวเอง (แนะนำ)
  เหมาะสำหรับใช้งานส่วนตัวหรือองค์กร (ฟรี ไม่ต้องมีเซิร์ฟเวอร์กลาง):
  - ขั้นที่ 1 — FB App ID:
    กดปุ่ม "เปิดหน้า Meta Apps ↗" เพื่อสร้างหรือดูแอปประเภท Business ใน
    Meta Developer แล้วนำ App ID มาวาง
  - ขั้นที่ 2 — FB App Secret:
    กดปุ่ม "เปิดหน้าดู App Secret ตรงนี้เลย ↗" คัดลอก App Secret มาวาง
    (มีสวิตช์ "แสดง App Secret" และจะบันทึกลง Windows Keychain อัตโนมัติ)
  - ขั้นที่ 3 — Redirect URI:
    กด "คัดลอก" ค่า http://localhost:8765/callback แล้วกด
    "เปิดหน้าวาง Redirect URI ↗" เพื่อนำไปใส่ในช่อง Valid OAuth Redirect URIs
    ของ Facebook Login
  - ขั้นที่ 4 — ทดสอบ & บันทึก:
    ตรวจสอบเวอร์ชัน Graph API (ค่าเริ่มต้น v22.0) กดปุ่ม
    "ขั้นที่ 4: ทดสอบ App ID / Secret" จากนั้นกด "บันทึกการตั้งค่า"
  - ตัวเลือกเพิ่มเติมในแท็บนี้:
    สวิตช์ "ย่อเก็บลง System Tray เมื่อกดปิดหน้าต่าง" เพื่อเปิดให้โปรแกรม
    ทำงานต่อเบื้องหลังสำหรับส่งคิวตั้งเวลา

[รูปแบบที่ 2] แท็บ "2. One-Click Backend" — เชื่อมต่อผ่านเซิร์ฟเวอร์กลาง
  เหมาะสำหรับผู้ใช้ที่รับโปรแกรมไปใช้ต่อจากผู้ดูแลระบบที่ติดตั้ง Backend
  ไว้แล้ว (ผู้ใช้ไม่ต้องสร้าง Meta App เอง):
  - เปิดสวิตช์ "เปิดใช้โหมด One-Click ผ่าน Backend Server"
  - วาง Backend URL (ต้องขึ้นต้นด้วย https:// สำหรับเซิร์ฟเวอร์ภายนอก;
    อนุญาต http://localhost หรือ http://127.0.0.1 เฉพาะการทดสอบในเครื่อง)
  - กด "ทดสอบการเชื่อมต่อ Server" แล้วกด "บันทึกการตั้งค่า"

[รูปแบบที่ 3] แท็บ "3. วาง Token โดยตรง" — ไม่ต้องใส่ App ID / Secret
  - กด "เปิด Graph API Explorer ↗" เพื่อสร้าง Page Access Token หรือ
    User Access Token ที่มีสิทธิ์ครบ:
    pages_show_list, pages_manage_posts,
    pages_read_engagement, pages_manage_engagement, read_insights
  - วาง Token ลงในช่องแล้วกด "ดึงเพจและเชื่อมต่อด้วย Token นี้ทันที"
  - หากเป็น User Token ระบบจะดึงเพจทั้งหมดที่จัดการอยู่ (รองรับหลายหน้า)
  - หากเป็น Page Access Token ระบบจะดึงข้อมูลเพจนั้นโดยตรง
  - หมายเหตุ: ระบบจะปฏิเสธ User Token ส่วนตัวที่ไม่มีเพจจัดการ

ปุ่ม "สำรองฐานข้อมูล (Backup DB)" (มุมล่างซ้ายของหน้าต่างตั้งค่า):
  - กดเพื่อสำรองไฟล์ฐานข้อมูล SQLite (data.db) อย่างปลอดภัยในขณะเปิดแอป
    เพื่อเก็บประวัติโพสต์, คิวตั้งเวลา, เทมเพลต, ชุดเพจ และสมุดบันทึกกลุ่มไว้

========================================================================
2. ภาพรวมหน้าจอ: แถบด้านซ้าย (Sidebar) และแถบสถิติ KPI ด้านบน
========================================================================

[แถบด้านซ้าย — Sidebar]
  1) เมนูหลัก (5 หน้า):
     - เขียนโพสต์        : สร้างโพสต์, แนบสื่อ, ลายน้ำ, ตั้งเวลา, คอมเมนต์ต่อท้าย
     - คิวตั้งเวลา       : จัดการคิวในเครื่อง, แก้ไขคิว, ส่งซ้ำ, นำเข้า CSV
     - ประวัติการโพสต์   : ดูประวัติ, โพสต์ซ้ำ, ดูสถิติ, แก้ไข/ลบโพสต์บน FB
     - คอมเมนต์ใต้โพสต์  : โหลดโพสต์, กล่องตอบ/ซ่อน/ลบคอมเมนต์, คิวคอมเมนต์
     - แชร์โพสต์         : แชร์โพสต์ลงเพจที่เลือก และสมุดบันทึกกลุ่ม Facebook

  2) จัดการเพจที่เชื่อมต่อ:
     - ช่อง "ค้นหาชื่อเพจ…": กรองรายชื่อเพจแบบเรียลไทม์
     - ติ๊กช่องสี่เหลี่ยมหน้าชื่อเพจเพื่อเลือกเพจเป้าหมายที่จะโพสต์หรือแชร์
     - ปุ่ม "เลือกทั้งหมด": ติ๊กเลือกเฉพาะเพจที่แสดงอยู่ (หลังกรองค้นหา)
     - ปุ่ม "ไม่เลือก": ล้างการติ๊กเลือกทั้งหมด (รวมถึงเพจที่ถูกซ่อนอยู่)

  3) ชุดเพจ (Page Presets — บันทึกกลุ่มเพจที่ใช้บ่อย):
     - ติ๊กเลือกเพจที่ต้องการ แล้วกดปุ่ม "+ ชุดเพจ" เพื่อตั้งชื่อบันทึกไว้
     - เลือกชุดเพจจากช่องดรอปดาวน์เพื่อติ๊กเลือกเพจชุดนั้นทันทีในคลิกเดียว
       (สามารถคลิกเลือกชุดเพจเดิมซ้ำได้ และระบบจะล้างคำค้นหาให้อัตโนมัติ
       เพื่อให้เห็นเพจที่ถูกติ๊กครบทุกตัว)
     - กดปุ่ม "×" ด้านขวาเพื่อลบชุดเพจที่กำลังเลือกอยู่

  4) ปุ่มจัดการบัญชีและการเชื่อมต่อ:
     - ปุ่ม "ตรวจสถานะ Token": ตรวจสอบ Token ของทุกเพจพร้อมกัน
       แสดงสถานะ 🟢 (ใช้งานได้ปกติ) หรือ 🔴 (หมดอายุ/มีปัญหา ต้องเชื่อมต่อใหม่)
     - ปุ่ม "เชื่อมต่อ Facebook": เปิดเบราว์เซอร์เพื่อเข้าสู่ระบบ OAuth
       (ระหว่างรอล็อกอินสามารถกด "ยกเลิกการเชื่อมต่อ" ได้ทุกเมื่อ)
     - ปุ่ม "ลบเพจที่เลือก": ลบเพจออกจากโปรแกรมและลบ Token ออกจาก Keychain

  5) แถบเครื่องมือมุมล่างซ้าย:
     - ปุ่มสลับโหมดมืด/สว่างแบบแอนิเมชันท้องฟ้า (ดวงอาทิตย์+เมฆ <-> ดวงจันทร์+ดาว):
       คลิกเพื่อสลับธีม Light / Dark และบันทึกค่าให้อัตโนมัติ
     - ปุ่ม "ตั้งค่า": เปิดหน้าต่างตั้งค่าการเชื่อมต่อและ Backup DB

[แถบสถิติ KPI ด้านบน — 4 การ์ด]
  - เพจที่เชื่อมต่อ   : จำนวนเพจทั้งหมดที่เชื่อมต่อไว้
  - เพจที่เลือกโพสต์  : จำนวนเพจที่กำลังติ๊กเลือกอยู่
  - รอในคิวตั้งเวลา   : จำนวนคิวในเครื่องที่รอส่ง (pending) หรือกำลังส่ง (running)
  - โพสต์สำเร็จทั้งหมด : จำนวนโพสต์สถานะ published ทั้งหมดในประวัติ

========================================================================
3. หน้า 1: เขียนโพสต์ (Composer) & พรีวิวแบบเรียลไทม์
========================================================================

[ข้อความ, เทมเพลต และลิงก์]
  - เทมเพลตแคปชัน & ชุดแฮชแท็ก:
    กด "จัดการเทมเพลต / แฮชแท็ก" เพื่อเพิ่มหรือลบเทมเพลต (แยกประเภท
    "เทมเพลตแคปชัน" และ "ชุดแฮชแท็ก") จากนั้นเลือกจากดรอปดาวน์แล้วกด
    "แทรกเทมเพลต" เพื่อต่อท้ายข้อความในช่องเขียนโพสต์
  - ข้อความโพสต์:
    พิมพ์ได้สูงสุด 63,206 ตัวอักษร พร้อมตัวนับมุมขวาบนคอยแจ้งเตือนหากเกิน
  - แนบลิงก์ (ไม่บังคับ):
    ใส่ URL ที่ขึ้นต้นด้วย http:// หรือ https://

[การแนบสื่อ: รูปภาพ หรือ วิดีโอ]
  - แนบรูปภาพ:
    ลากไฟล์รูป (.png, .jpg, .jpeg, .webp, .gif, .bmp) มาวางในกรอบ
    หรือกดปุ่ม "เลือกรูปภาพ" / "+ เพิ่ม" (รองรับทั้งรูปเดี่ยวและหลายรูป)
    * ระบบตรวจจับไฟล์ซ้ำอัตโนมัติ (ไม่แนบไฟล์เดิมซ้ำ) และปรับทิศทางภาพถ่าย
      แนวตั้งจากมือถือ (EXIF Auto-Orient) ให้อัตโนมัติไม่ให้ภาพตะแคง
    * รูปเดี่ยวอัปโหลดผ่าน /{page_id}/photos
    * หลายรูปอัปโหลดแบบยังไม่เผยแพร่แล้วรวมเป็นโพสต์เดียวผ่าน /{page_id}/feed
  - แนบวิดีโอ & โหมด Facebook Reels:
    * กด "+ วิดีโอ (MP4)" รองรับ .mp4, .mov, .m4v, .avi, .mkv, .webm
    * เมื่อแนบวิดีโอแล้ว สามารถเปิดสวิตช์ "ส่งเป็น Reels" เพื่อโพสต์เป็น Facebook Reels
      ผ่านโปรโตคอลทางการ 3 ขั้นตอน (/{page_id}/video_reels + rupload.facebook.com)
    * โหมด Reels รองรับทั้งโพสต์ทันทีหลายเพจ, ตั้งเวลา FB Native (10 นาที – 29 วัน),
      คิวตั้งเวลาในเครื่อง, คอมเมนต์ต่อท้ายโพสต์อัตโนมัติ และการนำเข้าผ่าน CSV (คอลัมน์ is_reel=1)
    * หมายเหตุ: Facebook Reels API ไม่รองรับการแนบสถานที่เช็คอิน (Check-in)
  - คลังชุดโพสต์สำเร็จรูป (Post Presets / Content Packs):
    * กดปุ่ม "ชุดโพสต์" ด้านบนช่องพิมพ์ข้อความ เพื่อบันทึกทุกอย่างในหน้าเขียนโพสต์ปัจจุบัน
      (ข้อความ + ลิงก์ + รูป/วิดีโอ/Reels + ลายน้ำ + เช็คอิน + คอมเมนต์ต่อท้าย) เก็บไว้เป็นชุดสำเร็จรูป
    * โหลดชุดโพสต์กลับมาพร้อมโพสต์ลงหลายเพจได้ในคลิกเดียว (พร้อมตรวจสอบไฟล์สื่อในเครื่องให้อัตโนมัติ)
  - ข้อควรรู้:
    * Facebook ไม่รองรับการแนบทั้งรูปภาพและวิดีโอในโพสต์เดียวกัน
      (หากเลือกอย่างหนึ่ง ระบบจะล้างอีกอย่างให้อัตโนมัติ)
    * หากแนบลิงก์พร้อมรูปภาพหรือวิดีโอ ระบบจะต่อท้ายลิงก์ลงในข้อความให้เอง

[เช็คอินสถานที่ (Check-in)]
  - 📍 เช็คอินสถานที่:
    * ใส่เลข Facebook Place ID หรือวางลิงก์เพจสถานที่ (เช่น https://www.facebook.com/pages/.../123456789)
      หรือกดปุ่ม "ค้นหา/เลือก" เพื่อค้นหาผ่าน Facebook Graph API และบันทึกสถานที่ที่ใช้บ่อยเก็บไว้ใช้ซ้ำได้
  - ใช้งานร่วมกับโพสต์ข้อความ, ลิงก์, รูปเดี่ยว, รูปหลายรูป, คลิปวิดีโอ, คิวตั้งเวลา และการโพสต์ซ้ำได้ครบถ้วน
  - แสดงตัวอย่างเช็คอินแบบเรียลไทม์บนพรีวิวฝั่งขวา
  - หมายเหตุ: ฟีเจอร์ "กิจกรรม/ความรู้สึก" (og_action_type_id) ถูกถอดออกเนื่องจาก Meta ปิดการใช้งานบน Facebook Graph API รุ่นใหม่แล้ว

[การตั้งเวลาโพสต์ & ทำซ้ำอัตโนมัติ]
  เปิดสวิตช์ "ตั้งเวลาโพสต์", เลือกวันเวลาในปฏิทิน (ตั้งแต่ปี ค.ศ. 2000 เป็นต้นไป)
  และเลือกโหมด:
  1) FB Native (ตั้งเวลาบนเซิร์ฟเวอร์ Facebook — ปิดแอปได้):
     - ต้องตั้งเวลาล่วงหน้าอย่างน้อย 10 นาที และไม่เกิน 75 วัน
     - ไม่รองรับคอมเมนต์ต่อท้ายอัตโนมัติและระบบทำซ้ำ
  2) คิวในเครื่อง (ส่งอัตโนมัติขณะเปิดแอปหรือย่อลง System Tray):
     - ระบบตรวจสอบคิวทุก 20 วินาที และทยอยส่งต่อเนื่องเมื่อถึงเวลา
     - รองรับทั้ง "คอมเมนต์ต่อท้ายโพสต์อัตโนมัติ", "ลายน้ำ" และ "ตั้งเวลาทำซ้ำ"
     - ตัวเลือกการทำซ้ำ: "ไม่ทำซ้ำ", "ซ้ำรายวัน", หรือ "ซ้ำรายสัปดาห์"
       (เมื่อโพสต์สำเร็จ คิวจะเลื่อนวันเวลาไปรอบถัดไปให้อัตโนมัติ)

[คอมเมนต์ต่อท้ายโพสต์อัตโนมัติ]
  - พิมพ์ข้อความ (เช่น พิกัดสินค้า, ลิงก์สั่งซื้อ) แล้วกด "+ เพิ่ม" หรือ Enter
  - เพิ่มได้หลายคอมเมนต์ และตั้งค่าหน่วงเวลาระหว่างแต่ละคอมเมนต์ (0–60 วิ)
  - ใช้งานได้ทั้งแบบโพสต์ทันทีและแบบตั้งเวลาในโหมด "คิวในเครื่อง"

[หน่วงเวลาระหว่างเพจ (ป้องกันสแปมเมื่อโพสต์/แชร์หลายเพจ)]
  - กำหนดเวลาหน่วงขั้นต่ำ–สูงสุด (0–300 วินาที)
  - ระบบจะสุ่มเวลาพักระหว่างแต่ละเพจ (หากตั้งเป็น 0 จะส่งต่อเนื่องทันที)
  - ใช้ร่วมกันทั้งการโพสต์หลายเพจ, คิวตั้งเวลา และการแชร์ลงหลายเพจ

[พรีวิวโพสต์บน Facebook — Live Preview ฝั่งขวา]
  - จำลองหน้าตาโพสต์จริงแบบเรียลไทม์ ทั้งชื่อเพจ, เวลาที่ตั้ง, ข้อความ,
    การ์ดลิงก์, ป้ายวิดีโอ และตารางรูปภาพสูงสุด 4 ช่องพร้อมแบดจ์จำนวนรูปที่เหลือ

4. ระบบ Spintax, ตัวแปรไดนามิก, ลายน้ำอัตโนมัติ และบันทึกฉบับร่าง
========================================================================

[Spintax และตัวแปรไดนามิก]
  ช่วยให้ข้อความที่โพสต์ลงหลายเพจไม่ซ้ำกันทุกตัวอักษร ลดความเสี่ยงสแปม:
  - Spintax สุ่มคำ: ใช้รูปแบบ {ตัวเลือกที่1|ตัวเลือกที่2|ตัวเลือกที่3}
    ตัวอย่าง: "{สวัสดีครับ|ทักทายครับ} วันนี้มี{โปรเด็ด|ดีลพิเศษ}มาฝาก!"
  - ตัวแปรไดนามิก:
    * {page_name} -> แทนที่ด้วยชื่อเพจเป้าหมายแต่ละเพจโดยอัตโนมัติ
    * {date}      -> แทนที่ด้วยวันที่ปัจจุบัน (YYYY-MM-DD)
    * {time}      -> แทนที่ด้วยเวลาปัจจุบัน (HH:MM)
  - รองรับการใช้งานใน: ข้อความโพสต์, คอมเมนต์ต่อท้าย, คิวคอมเมนต์,
    ข้อความลายน้ำบนรูปภาพ และปุ่มคัดลอกข้อความลงคลิปบอร์ด

[ประทับลายน้ำข้อความบนรูปอัตโนมัติ (Auto Text Watermark)]
  - เปิดสวิตช์ "ประทับลายน้ำบนรูป:" ในหน้าเขียนโพสต์ แล้วพิมพ์ข้อความ
    เช่น "© {page_name}" หรือ "โปรวันนี้ {date}"
  - ระบบจะประทับป้ายลายน้ำมุมขวาล่างลงบนไฟล์ชั่วคราวก่อนอัปโหลด
    (ไม่แก้ไขไฟล์ต้นฉบับในเครื่อง และลบทิ้งอัตโนมัติหลังอัปโหลดเสร็จ)
  - รองรับการแก้/ปรับทิศทางภาพถ่ายมือถือ (EXIF Auto-Orient) ก่อนประทับลายน้ำ
  - หากส่งเข้าคิวตั้งเวลาในเครื่อง แต่ละคิวจะเก็บข้อความลายน้ำของตัวเองไว้แยกกัน

[บันทึกฉบับร่างอัตโนมัติ (Auto-Save Draft)]
  - ระบบจะบันทึกสิ่งที่กำลังพิมพ์ (ข้อความ, ลิงก์, รูป/วิดีโอที่แนบ,
    คอมเมนต์ต่อท้าย และการตั้งค่าลายน้ำ) ให้อัตโนมัติเมื่อหยุดพิมพ์ชั่วครู่
    หรือเมื่อปิดโปรแกรม เมื่อเปิดโปรแกรมใหม่ข้อมูลเดิมจะกลับมาทันที
  - หลังโพสต์สำเร็จหรือเพิ่มเข้าคิวแล้ว ระบบจะล้างฉบับร่างให้อัตโนมัติ

5. หน้า 2: คิวตั้งเวลาในเครื่อง (Local Queue) & การนำเข้า CSV
========================================================================

แสดงรายการคิวในโหมด "คิวในเครื่อง" ที่มีสถานะ 🕒 รอโพสต์, ⏳ กำลังโพสต์
และ ❌ ล้มเหลว (พร้อมป้าย 🔁 รายวัน / รายสัปดาห์ หากตั้งทำซ้ำไว้):

  - ปุ่ม "โพสต์ทันที"      : สั่งส่งคิวที่เลือกทันทีโดยไม่ต้องรอถึงเวลา
  - ปุ่ม "แก้ไขคิว"        : เปิดหน้าต่างแก้ไขวันเวลา, กฎการทำซ้ำ, ข้อความ,
                             ลิงก์แนบ, เพิ่ม/เปลี่ยนรูปภาพหรือคลิปวิดีโอ และลายน้ำบนรูปภาพ
                             (หากตั้งเวลาในอดีต โปรแกรมจะถามยืนยันก่อนบันทึกเพื่อกันโพสต์ทันทีโดยไม่ตั้งใจ)
  - ปุ่ม "ส่งซ้ำที่ล้มเหลว" : รีเซ็ตคิวที่สถานะล้มเหลวทั้งหมดกลับมาเป็นรอส่ง
                             และเริ่มส่งคิวที่ถึงเวลาแล้วทันที
  - ปุ่ม "นำเข้า CSV"      : นำเข้าคิวตั้งเวลาทีละหลายรายการลงเพจที่ติ๊กเลือกไว้
  - ปุ่ม "ยกเลิกคิว"       : ลบคิวที่เลือกออกจากระบบ (มีหน้าต่างยืนยัน)
  - ปุ่ม "รีเฟรช"          : โหลดรายการคิวล่าสุด

[รูปแบบไฟล์ CSV สำหรับปุ่ม "นำเข้า CSV"]
  - รองรับทั้งไฟล์ UTF-8 (utf-8-sig) และไฟล์ CSV จาก Excel ภาษาไทย (cp874)
  - รองรับทั้งหัวตารางภาษาอังกฤษและภาษาไทย:
    run_at (หรือ เวลา), message (หรือ ข้อความ),
    link (หรือ ลิงก์), image_paths (หรือ รูปภาพ — คั่นหลายไฟล์ด้วย ;),
    video_path (หรือ วิดีโอ),
    repeat_rule (หรือ ทำซ้ำ — daily/weekly/รายวัน/รายสัปดาห์),
    watermark_text (หรือ ลายน้ำ)
  - รูปแบบวันเวลาที่รองรับ: YYYY-MM-DD HH:MM, YYYY/MM/DD HH:MM,
    DD/MM/YYYY HH:MM รวมถึงปี พ.ศ. ไทย (เช่น 2569-12-01 09:00 หรือ
    29/02/2567 09:30 ระบบจะแปลงเป็นปี ค.ศ. ให้อัตโนมัติ)

  หมายเหตุ: หากปิดโปรแกรมระหว่างคิวกำลังส่ง เมื่อเปิดโปรแกรมใหม่ระบบจะ
  เปลี่ยนสถานะคิวที่ค้างให้เป็น "ล้มเหลว" อัตโนมัติเพื่อไม่ให้ค้างหรือโพสต์ซ้ำ

6. หน้า 3: ประวัติการโพสต์ (History), ดูสถิติ, แก้ไข และลบโพสต์บน FB
========================================================================

  - ตัวกรองสถานะด้านบนขวา: ทั้งหมด / โพสต์สำเร็จ / ตั้งเวลาแล้ว / ล้มเหลว
  - รองรับการเลือกหลายเพจพร้อมกัน (Multi-Selection):
    * ลากเมาส์คลุมหลายแถว หรือกด Ctrl+คลิก / Shift+คลิก เพื่อเลือกหลายเพจ
    * ปุ่ม "เลือกทั้งชุด": คลิกโพสต์ใดก็ได้ 1 แถวแล้วกดปุ่มนี้ ระบบจะเลือก
      ทุกเพจที่ถูกโพสต์พร้อมกันในชุดเดียวกันให้อัตโนมัติในคลิกเดียว
  - ปุ่ม "โพสต์ซ้ำ" : ดึงข้อความ, ลิงก์ และรูป/วิดีโอเดิมกลับไปหน้าเขียนโพสต์
                      (และล้างคอมเมนต์ต่อท้ายที่ค้างอยู่ในหน้าเขียนโพสต์ให้สะอาด)
  - ปุ่ม "ดูสถิติ"  : ดึงยอด 👍 ถูกใจ, 💬 คอมเมนต์, 📤 แชร์ และลิงก์โพสต์
                      ล่าสุดจาก Facebook Graph API
  - ปุ่ม "แก้ไขโพสต์" (แก้ไขข้อความโพสต์ทับโพสต์เดิม รองรับหลายเพจ):
    * หากคลิกโพสต์ที่มีชุดเพจเดียวกัน หน้าต่างแก้ไขจะมีสวิตช์
      "แก้ไขข้อความทุกเพจในชุดโพสต์เดียวกันพร้อมกัน (N เพจ)" เปิดไว้ให้อัตโนมัติ
      หรือจะเลือกหลายแถวในตารางก่อนกดแก้ไขก็ได้
    * รองรับ Spintax {A|B} และตัวแปร {page_name}, {date}, {time}
    * อัปเดตเฉพาะ "ข้อความ" ทับโพสต์เดิมโดยตรงทั้งโพสต์รูปภาพ/ข้อความ และโพสต์วิดีโอ
      (รักษา Post ID เดิม รูปภาพ/วิดีโอ เช็คอิน ยอดไลก์ และคอมเมนต์เดิมครบถ้วน — ไม่ลบโพสต์เดิมเด็ดขาด)
    * หมายเหตุ: เนื่องจาก Facebook Graph API ไม่อนุญาตให้เปลี่ยนรูปภาพ/วิดีโอ หรือเช็คอินบนโพสต์ที่เผยแพร่แล้ว
      หากต้องการแก้สื่อ สามารถกดปุ่ม "เปิดแก้สื่อ/เช็คอินบนเว็บ Facebook" ในหน้าต่างแก้ไขเพื่อเปิดแก้บนเว็บ Facebook ได้ทันที
      (ส่วนโพสต์ที่อยู่ใน "คิวตั้งเวลา" ยังสามารถแก้ไขรูปภาพ วิดีโอ ลิงก์ และเช็คอินได้ครบถ้วนก่อนถึงเวลาโพสต์)
  - ปุ่ม "คอมเมนต์" : ส่งเพจและ Post ID ไปหน้า "คอมเมนต์ใต้โพสต์" ทันที
                      (หากเพจต้นทางถูกลบออกจากโปรแกรมแล้ว ระบบจะแจ้งเตือน)
  - ปุ่ม "แชร์โพสต์": ส่งลิงก์ Permalink และข้อความเดิมไปหน้า "แชร์โพสต์" ทันที
  - ปุ่ม "ลบประวัติ": ลบแถวประวัติที่เลือกในเครื่อง (รองรับลบทีละหลายแถวพร้อมกัน)
  - ปุ่ม "ลบจาก FB" : ลบโพสต์ออกจากหน้าเพจบน Facebook อย่างถาวร (รองรับการเลือก
                      ลบทีเดียวหลายเพจพร้อมกัน มีหน้าต่างยืนยันแสดงรายชื่อเพจ)
  - ปุ่ม "ล้างทั้งหมด": ล้างประวัติการโพสต์ทั้งหมดในฐานข้อมูลในเครื่อง

7. หน้า 4: คอมเมนต์ใต้โพสต์, กล่องตอบ/ซ่อน/ลบคอมเมนต์ & เพจอื่น
========================================================================

[ฝั่งซ้าย — 1. เลือกเพจและโพสต์]
  - เลือกเพจจากดรอปดาวน์แล้วกด "โหลดโพสต์ล่าสุด" (ดึงสูงสุด 20 โพสต์ล่าสุด)
  - คลิกเลือกโพสต์จากรายการเพื่อเติม Post ID อัตโนมัติ
  - ปุ่ม "แก้ไขโพสต์ที่เลือกบน FB": แก้ไขข้อความโพสต์เก่าบนเพจได้โดยตรง
  - ปุ่ม "ลบโพสต์บน FB": ลบโพสต์ที่เลือกออกจากหน้าเพจบน Facebook ถาวร
  - ช่องวางลิงก์โพสต์ / Post ID + ปุ่ม "แกะลิงก์":
    รองรับทั้ง Post ID ตรง (123456_789012, 789012), ลิงก์ /posts/...,
    ลิงก์แบบใหม่ที่มีชื่อหัวข้อคั่น (/posts/<ชื่อเรื่อง>/<pfbid หรือ id>),
    permalink.php?story_fbid=..., /videos/..., /reel/..., /reels/...,
    /photo/?fbid=..., /watch/?v=..., รหัส pfbid และลิงก์แชร์สั้น
    (/share/p/..., fb.watch/...)
  - ปุ่ม "กล่องอ่านและตอบคอมเมนต์ของโพสต์นี้" (Comment Inbox):
    เปิดหน้าต่างอ่านคอมเมนต์ทั้งหมดใต้โพสต์นั้น พร้อมเครื่องมือจัดการครบ:
    * ตอบกลับคอมเมนต์ที่เลือกในนามเพจ
    * ปุ่ม "ซ่อนคอมเมนต์" / "เลิกซ่อนคอมเมนต์": แสดงป้าย "[ซ่อนแล้ว]"
      ให้เห็นชัดเจนตั้งแต่โหลดรายการ และสลับซ่อนหรือเลิกซ่อนบน Facebook ได้จริง
    * ปุ่ม "ลบคอมเมนต์": ลบคอมเมนต์ออกจากโพสต์บน Facebook ถาวร
  - ระบบตอบคอมเมนต์อัตโนมัติตามคีย์เวิร์ด (Keyword Auto-Reply):
    * กดปุ่ม "ตั้งค่ากฎคีย์เวิร์ด…" เพื่อเพิ่มกฎคีย์เวิร์ดได้ไม่จำกัด
      รองรับทั้งโหมด "มีคำนี้อยู่ในเม้นต์ (Contains)" และ "ตรงทั้งประโยค (Exact)"
    * ข้อความตอบกลับรองรับ Spintax {สวัสดีครับ|ยินดีให้บริการครับ} และตัวแปร
      {commenter_name} (ชื่อผู้คอมเมนต์), {page_name}, {date}, {time}
    * เลือกเปิดออปชัน "ซ่อนคอมเมนต์หลังตอบ" เพื่อป้องกันเพจคู่แข่งส่องลูกค้าได้
    * มีระบบบันทึก comment_id กันตอบซ้ำ 100% และข้ามคอมเมนต์ของเพจตัวเองอัตโนมัติ
    * สั่งทำงานได้ทั้งกดปุ่ม "⚡ ตรวจตอบตอนนี้" และเปิดสวิตช์ทำงานอัตโนมัติเบื้องหลังตามรอบเวลา (ทุก 1–30 นาที)

[ฝั่งขวา — 2. คิวคอมเมนต์หลายอัน]
  - เพิ่มคอมเมนต์พร้อมรูปภาพ:
    พิมพ์ข้อความ และ/หรือ กด "📎 แนบรูปในคอมเมนต์" แล้วกด
    "+ เพิ่มเป็น 1 คอมเมนต์" (รองรับทั้งข้อความล้วน, ข้อความ+รูป หรือเฉพาะรูป)
  - เพิ่มทีเดียวหลายอัน:
    วางหลายบรรทัดแล้วกด "+ แยกทีละบรรทัด (หลายอัน)"
  - จัดลำดับด้วยปุ่ม ขึ้น / ลง / ลบ / ล้างทั้งหมด และตั้งเวลาหน่วง (0–60 วินาที)
  - ปุ่ม "ส่งคอมเมนต์ทั้งหมด": ส่งผ่าน Graph API ในนามเพจ (รองรับ Spintax
    และตัวแปร {page_name}, {date}, {time}; ตรวจสอบไฟล์รูปก่อนส่งอัตโนมัติ)
  - ผู้ช่วยคอมเมนต์สำหรับเพจอื่น (ปลอดภัย ไม่ใช้บอท):
    * "คัดลอกและเปิดโพสต์ในเบราว์เซอร์ (สำหรับเพจอื่น)": ขยาย Spintax,
      คัดลอกลงคลิปบอร์ด, เลื่อนตัวชี้รออันถัดไป และเปิดหน้าโพสต์ให้กด Ctrl+V วางเอง
    * "คัดลอกอันถัดไป": คัดลอกคอมเมนต์ถัดไปลงคลิปบอร์ดทันทีโดยไม่เปิดแท็บซ้ำ

8. หน้า 5: แชร์โพสต์ลงเพจตัวเอง และสมุดบันทึกกลุ่ม (Quick Share)
========================================================================

[ฝั่งซ้าย — 1. สมุดบันทึกกลุ่ม Facebook]
  - กรอกชื่อกลุ่มและวางลิงก์กลุ่ม (https://www.facebook.com/groups/...)
    แล้วกด "+ บันทึกกลุ่มเข้าสมุด" (อนุญาตเฉพาะโดเมนของ Facebook)
  - ติ๊กเลือกกลุ่มเป้าหมาย (มีปุ่ม เลือกทั้งหมด / ไม่เลือก / ลบที่เลือก)

[ฝั่งขวา — 2. แชร์โพสต์ลงเพจตัวเอง / ลงกลุ่ม]
  - กด "ดึงโพสต์ล่าสุดจากประวัติ" หรือวางลิงก์โพสต์ใดก็ได้พร้อมพิมพ์แคปชัน
    (แคปชันรองรับ Spintax และตัวแปร {page_name}, {date}, {time})
  - เลือกวิธีแชร์ได้ 4 แบบ:
    1) ปุ่ม "แชร์ลงหน้าเพจที่ติ๊กเลือก (N เพจ)":
       แชร์ลิงก์โพสต์พร้อมแคปชันลงหน้าเพจของคุณที่ติ๊กเลือกไว้ทางแถบซ้าย
       ผ่าน Graph API ทันที (รองรับหน่วงเวลาระหว่างเพจ)
    2) ปุ่ม "คัดลอกและเปิดกลุ่มที่ติ๊ก (N กลุ่ม)":
       คัดลอกแคปชัน+ลิงก์ลงคลิปบอร์ดแล้วเปิดแท็บทุกกลุ่มที่ติ๊กในเบราว์เซอร์
       เพื่อให้กด Ctrl+V แชร์ด้วยตัวเองอย่างปลอดภัย 100% (ถามยืนยันหากเกิน 5 กลุ่ม)
    3) ปุ่ม "เปิดหน้าต่างแชร์ Facebook (Share Dialog)":
       คัดลอกข้อความและเปิดหน้าต่าง sharer.php ทางการของ Facebook
    4) ปุ่ม "คัดลอกลิงก์ + ข้อความ": คัดลอกลงคลิปบอร์ดอย่างเดียว

  หมายเหตุ: Meta ยกเลิก Groups API สำหรับการโพสต์เข้ากลุ่มอัตโนมัติตั้งแต่
  เมษายน 2024 ฟังก์ชันแชร์ลงกลุ่มจึงออกแบบให้ช่วยคัดลอกและเปิดแท็บอย่างปลอดภัย

9. การทำงานเบื้องหลังผ่าน System Tray และการสำรอง/กู้คืนฐานข้อมูล (Auto-Backup & Restore)
========================================================================

  - เปิดใช้งานได้ที่หน้า "ตั้งค่า" -> แท็บ 1 -> เปิดสวิตช์
    "ย่อเก็บลง System Tray เมื่อกดปิดหน้าต่าง"
  - เมื่อกดปุ่มกากบาท (×) ปิดหน้าต่างหลัก โปรแกรมจะซ่อนลงถาดมุมขวาล่าง
    (System Tray) เพื่อรอส่งคิวโพสต์ตั้งเวลาและตอบคอมเมนต์อัตโนมัติเบื้องหลัง
    พร้อมแจ้งเตือนผ่าน Tray Notification เมื่อทำงานสำเร็จหรือพบข้อผิดพลาด
  - วิธีเปิดหน้าต่างกลับมา: คลิกหรือดับเบิลคลิกที่ไอคอนโปรแกรมใน System Tray
    หรือคลิกขวาแล้วเลือก "เปิดโปรแกรม Prince Studio"
  - วิธีปิดโปรแกรมจริง: คลิกขวาที่ไอคอนใน System Tray แล้วเลือก "ออกจากโปรแกรม"
  - ระบบสำรองและกู้คืนฐานข้อมูล (Auto-Backup 7 วัน + Restore DB):
    * ทุกครั้งที่เปิดโปรแกรม ระบบจะสำรองฐานข้อมูลแบบ WAL-safe ให้อัตโนมัติวันละ 1 ไฟล์
      เก็บไว้ที่โฟลเดอร์ ~/.social_manager/backups/auto_backup_YYYY-MM-DD.db (เก็บย้อนหลัง 7 วันล่าสุด)
    * ในหน้าต่าง "ตั้งค่า" มีทั้งปุ่ม "สำรองฐานข้อมูล (Backup DB)" สำหรับบันทึกเก็บเอง
      และปุ่ม "กู้คืนฐานข้อมูล (Restore)…" ซึ่งจะตรวจสอบความสมบูรณ์ของไฟล์ SQLite ก่อนกู้คืน
      พร้อมสำรองข้อมูลปัจจุบันไว้ที่ pre_restore_*.db ให้อัตโนมัติก่อนทับข้อมูลเสมอ

10. หน้า 6: RT Dashboard, Page Analytics & ระบบเปรียบเทียบเพจ
========================================================================

  เปิดดูภาพรวมผลงานทุกเพจได้จากหน้าเดียวผ่านเมนู "RT Dashboard / สถิติ" ทางซ้าย:

  [RT Dashboard (สรุปสดแบบเรียลไทม์)]
    - แสดงการ์ดสรุปรวม 4 ด้าน: Live Reach รวม, Live Engagement รวม,
      Impressions / Link Clicks รวม, และ Followers รวม / จำนวนเพจที่มีปัญหา
    - Auto Refresh: เปิดสวิตช์ "Auto Refresh" และเลือกรอบอัปเดตอัตโนมัติ
      (ทุก 1 นาที / 5 นาที / 15 นาที) ทำงานเบื้องหลังโดยไม่ขัดจังหวะการโพสต์
    - เลือกช่วงเวลาย้อนหลังได้: วันนี้ (1 วัน), 7 วันล่าสุด, หรือ 28 วันล่าสุด
    - กด "รีเฟรชข้อมูลตอนนี้" เพื่อดึงข้อมูลล่าสุดทันที หรือกด "ส่งออก CSV" เพื่อนำออกไปวิเคราะห์ต่อ

  [ระบบเปรียบเทียบเพจ (Page Comparison)]
    - เลือกเปรียบเทียบ "ทุกเพจที่เชื่อมต่อ" หรือ "เฉพาะเพจที่ติ๊กเลือกทางซ้าย"
    - ระบบวิเคราะห์และชี้เป้าให้อัตโนมัติทันที:
      * 🏆 เพจไหน Reach สูงสุด
      * 🔥 เพจไหน Engagement สูงสุด
      * 📉 เพจไหน Reach ลดลง (พร้อม % การลดลง)
      * 📈 เพจไหนมีการเติบโต (พร้อม % การเติบโต)
      * ⚠️ เพจไหนไม่มีข้อมูลอัปเดต หรือมีปัญหา (เช่น Token หมดอายุ)

  [ตาราง Page Analytics แยกตามเพจ]
    - แสดงครบทั้ง 8 ตัวชี้วัดหลัก: Reach, Impressions, Engagement, Reactions,
      Comments, Shares, Link Clicks, Followers พร้อมคอลัมน์แนวโน้ม Reach (%) และสถานะ
    - คลิกที่หัวคอลัมน์ตัวเลขเพื่อเรียงลำดับมาก→น้อย หรือ น้อย→มาก ได้ทันที
    - ดับเบิลคลิกที่แถวเพจเพื่อเลือกเฉพาะเพจนั้นแล้วสลับไปหน้า "เขียนโพสต์" ทันที
    - คลิกขวาที่แถวเพจเพื่อเปิดเมนูจัดการด่วน: เขียนโพสต์ลงเพจนี้, เปิดหน้าเพจบน Facebook,
      หรือตรวจสถานะ Token เฉพาะเพจนั้น

  [ฟีเจอร์เสริมอัตโนมัติสำหรับดูแลหลายเพจ]
    - ตรวจสถานะ Token อัตโนมัติตอนเปิดโปรแกรม: แสดงจุดสี 🟢 (ปกติ) / 🔴 (หมดอายุ)
      ข้างชื่อเพจทางซ้ายโดยไม่ขัดจังหวะการทำงาน
    - โหมดกระจายเวลาหลายเพจ (Anti-Spam Stagger): เลือกชุดเวลาสำเร็จรูป
      (เบา 10–30 วิ / กันสแปม 30–90 วิ / ปลอดภัย 60–180 วิ) ได้จากหน้าเขียนโพสต์
      รองรับทั้งการหน่วงเวลาระหว่างเพจตอนโพสต์ทันที และการกระจายเวลาโพสต์ห่างกันทีละเพจ
      ในโหมดตั้งเวลา FB Native อัตโนมัติ

11. คำถามที่พบบ่อยและการแก้ปัญหาเบื้องต้น
========================================================================

  Q: ขึ้น Error สิทธิ์ไม่พอเวลาโพสต์, อ่านสถิติ หรือคอมเมนต์?
  A: กด "ตรวจสถานะ Token" เพื่อเช็คเพจที่มีปัญหา (🔴) แล้วกด "เชื่อมต่อ Facebook"
     ใหม่ (หรือสร้าง Token ใหม่ใน Graph API Explorer) โดยเปิดสิทธิ์ให้ครบทั้ง
     pages_show_list, pages_manage_posts,
     pages_read_engagement, pages_manage_engagement, read_insights

  Q: ตั้งเวลาแบบ FB Native ไม่ผ่าน?
  A: ตรวจสอบว่าเวลาที่ตั้งอยู่ข้างหน้าอย่างน้อย 10 นาที และไม่เกิน 75 วัน
     และต้องไม่มีคอมเมนต์ต่อท้ายอัตโนมัติ (หากต้องการคอมเมนต์ต่อท้ายหรือทำซ้ำ
     ให้เปลี่ยนเป็นโหมด "คิวในเครื่อง")

  Q: นำเข้าไฟล์ CSV จาก Excel ภาษาไทยแล้วภาษาต่างดาวหรือเวลาผิด?
  A: โปรแกรมรองรับทั้ง UTF-8 และ cp874 (ANSI ไทยจาก Excel) รวมถึงปี พ.ศ. ไทย
     โดยอัตโนมัติ แต่ต้องแน่ใจว่าหัวคอลัมน์ตรงตามรูปแบบ (เช่น เวลา,ข้อความ)
     และใช้ปี ค.ศ. ตั้งแต่ 1970 (หรือ พ.ศ. 2400–2799)

  Q: ปุ่มกดไม่ได้ชั่วคราว?
  A: ระหว่างที่โปรแกรมกำลังอัปโหลดรูป/วิดีโอ หรือเรียก API เบื้องหลัง
     ปุ่มที่เกี่ยวข้องจะถูกล็อกชั่วคราวเพื่อป้องกันคำสั่งซ้อน เมื่อเสร็จสิ้น
     (สังเกตที่แถบสถานะด้านล่าง) ปุ่มจะกลับมาใช้งานได้ตามปกติ

  Q: แกะลิงก์สั้น /share/p/... หรือ fb.watch/... ไม่ได้?
  A: ในหน้า "คอมเมนต์ใต้โพสต์" แนะนำให้กด "โหลดโพสต์ล่าสุด" ของเพจ
     แล้วคลิกเลือกโพสต์จากรายการโดยตรงจะแม่นยำที่สุด

12. ระบบอัปเดตแพตช์สไตล์เกมออนไลน์ (SocialManagerLauncher.exe) & หน้าเว็บดาวน์โหลด
========================================================================

  [สำหรับผู้ใช้งาน]
  1. เปิดไฟล์ SocialManagerLauncher.exe (วางไว้ในโฟลเดอร์เดียวกับ SocialManager.exe)
  2. ครั้งแรก กดปุ่ม "⚙ ตั้งค่าช่องทางอัปเดต" แล้วใส่ชื่อ GitHub Repo (เช่น owner/repo)
     หรือวางลิงก์ไฟล์ version.json (https://...) จากนั้นกดบันทึก
  3. เมื่อมีแพตช์ใหม่ หน้าต่าง Launcher จะแสดงบันทึกการอัปเดต (Patch Notes) พร้อมรายการไฟล์
     กด "⬇ อัปเดตแพตช์" เพื่อดาวน์โหลดพร้อมหลอดแสดงเปอร์เซ็นต์และตรวจ SHA-256 อัตโนมัติ
  4. อัปเดตเสร็จแล้วกดปุ่มสีเขียว "▶ เข้าใช้งานโปรแกรม" เพื่อเปิด SocialManager.exe ได้ทันที
     (ข้อมูลเพจ ฐานข้อมูล data.db และ Token ในเครื่องจะอยู่ครบ 100% ไม่หาย)
  5. หากเปิดโปรแกรมหลัก (SocialManager.exe) ค้างอยู่ ให้ปิดโปรแกรมหลักก่อนกดอัปเดตแพตช์

  [สำหรับผู้ดูแลระบบ — วิธีปล่อยแพตช์บน GitHub Releases & GitHub Pages]
  1. อัปเดตเลขเวอร์ชันใน version.py แล้วรันคำสั่งสร้างแพตช์อัตโนมัติ:
     .\.venv\Scripts\python.exe build_release.py --repo <owner>/<repo> --notes "- รายละเอียดแพตช์"
  2. นำไฟล์ทั้งหมดในโฟลเดอร์ release_out/ (SocialManager.exe, SocialManagerLauncher.exe,
     คู่มือการใช้งาน.txt, version.json) ไปอัปโหลดใน GitHub Releases แท็ก v<เวอร์ชัน>
  3. (ไม่บังคับ) นำโฟลเดอร์ release_web/ (index.html + version.json) ไปเปิดใช้งานผ่าน
     GitHub Pages เพื่อให้ลูกค้าใหม่เข้าหน้าเว็บกดดาวน์โหลด Patch Launcher ได้ทันที
